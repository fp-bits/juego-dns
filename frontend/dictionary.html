Diccionario de DNS

Aquí tienes algunas definiciones breves para empezar:

A record Un tipo de registro DNS muy común. Contiene una dirección IPv4, como 1.2.3.4.
Servidor DNS autoritativo Es un tipo de servidor DNS. Cada dominio tiene asignado un servidor DNS autoritativo. Por lo general, las solicitudes DNS siguen este recorrido: 
tú -> resolvedor DNS -> servidor DNS
                         autoritativo
CNAME record Un tipo de registro DNS común. Contiene el nombre de host de un dominio, como example.com. Cómic sobre registros CNAME.
DNS name Cada vez que escribes un dominio, subdominio o subdominio de otro nivel en el navegador, ¡es un nombre DNS! Un nombre DNS (como bananas.prince.fruit.oops.pie.com.) debe:
  • tener menos de 255 caracteres;
  • cada parte (como «bananas») debe tener menos de 63 caracteres;
  • en teoría, estar compuesto solo por letras a-z, A-Z, números del 0 al 9 y guiones (-), aunque es común que los nombres de dominio también contengan guiones bajos (_).
Aparte de eso, las consultas DNS pueden contener cualquier nombre DNS.
DNS record Al hacer una consulta DNS, recibes cero o más registros como respuesta. Cada registro tiene al menos cuatro campos: el nombre, el TTL, el tipo y uno o más campos de contenido. Por ejemplo, la dirección IP de un registro A es su contenido.
DNS resolver Es un tipo de servidor DNS. Un resolvedor recibe tu solicitud, la envía al servidor DNS autoritativo correspondiente y guarda en caché el resultado. Puede que uses un resolvedor de Google, Cloudflare o tu proveedor de Internet.
DNS query Una consulta DNS es una solicitud que envías a un servidor DNS. Contiene dos campos: el nombre (como example.com) y el tipo (como «A»).
Subdomain Consulta «Nombre DNS».
TTL Significa Time To Live (tiempo de vida). Es un campo del registro DNS expresado en segundos. Los resolvedores DNS lo usan para decidir cuánto tiempo guardar el registro en caché.
