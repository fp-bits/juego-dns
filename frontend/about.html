Acerca de

¿Por qué creaste este sitio?

Estaba escribiendo un fanzine sobre DNS. Al final de muchos de mis fanzines digo: «¡la mejor forma de aprender es experimentar! Haz experimentos raros con DNS y observa cómo funciona». Pero me di cuenta de que la mayoría de las personas, aunque tengan un dominio, probablemente no se sienten cómodas haciendo experimentos raros con un dominio que sea importante para ellas.

Así que decidí crear un dominio solo para jugar (messwithdns.com) y permitir que cualquiera configure registros DNS. ¡Anímate a experimentar y a romper cosas!

Preguntas frecuentes

¡Encontré un error!

¡Me encantaría saberlo! Puedes informar de problemas del sitio en GitHub.

¿Cuál es la diferencia entre messwithdns.net y messwithdns.com?

La versión .net sirve el sitio web; en la versión .com puedes configurar registros DNS. Son dominios distintos para que el sitio sea más rápido, seguro y fiable (puedo usar un servidor DNS «real» para messwithdns.net).

¿Mess With DNS permite configurar todos los tipos de registros DNS?

Técnicamente, la API permite configurar cualquier tipo de registro DNS, pero la interfaz solo admite unos pocos. En particular, aún no he configurado DNSSEC, así que no hay una interfaz para los registros DNSSEC.

¿Puedo elegir cualquier subdominio?

No, solo puedes obtener un subdominio generado al azar, como banana17.messwithdns.com.

¿Debería usarlo para mi sitio web real?

No, tus registros DNS se eliminan después de una semana. Así se ahorra espacio en disco y se evita que alguien dependa del sitio para algo importante. Es solo para aprender.
